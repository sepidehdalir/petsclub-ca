# Product image approval pipeline

Do not use public listing photos as licensed assets. Keep unapproved products in compact text cards: no blank media panel or customer-facing asset-status labels.

Before importing a manufacturer photograph, archive written commercial permission and the original asset in the project evidence records. Verify the exact product model and variant against the manufacturer reference. Record the source URL, permission reference, review date, expiry if any, mandatory credit, and permitted offer IDs. A partner feed licence does not automatically allow using its creative to send visitors to Amazon.

Import an approved local asset as StaticImageData. The shared card uses a stable 4:3 contain region, native lazy loading, responsive sizes and Next image optimization. Metadata validation rejects mismatched models, missing review evidence, expired permission, incompatible offers and Amazon assets routed through the local pipeline. Actual rights require human evidence review; metadata alone is not permission.

Amazon photography requires its own approved official integration and must never be downloaded into this pipeline.
