# Pinterest and Reddit publication workflow

Three branded Pinterest assets are prepared in `pinterest/`, each with an editable SVG, a 1000 × 1500 PNG, caption, alternative text and a destination in `pins.json`. They promote published guides, contain no affiliate URL and make no therapeutic or hands-on testing claim. No external posts have been made.

## Pinterest publishing

Use the existing business account if the owner supplies access; do not create a duplicate identity. The [Pinterest specifications](https://help.pinterest.com/en/business/article/pinterest-product-specs) recommend a 2:3 image ratio. The supplied PNGs meet that format; the SVGs are editing sources, not upload files.

For each asset, confirm the destination returns 200 and the article is still published. Upload the PNG, use the recorded title, caption and alternative text, and select a relevant existing board. Add a commercial disclosure in both image/caption when a future Pin promotes a compensated placement. Keep the article's disclosure visible too. Publish manually once account access is available, then record the real Pin URL and date in `pins.json`.

Reuse the generator by updating its content records with claims drawn from the current article. Keep the brand, margin and type hierarchy; export fresh PNGs and inspect the result before posting. Check whether headline edits still fit the template.

Measure each real Pin's impressions, saves and outbound clicks in Pinterest. Search Console metrics are separate. Destination URLs include attribution parameters, but the privacy-preserving GA4 integration intentionally does not collect query strings; do not claim campaign-level GA attribution from these links without a separately reviewed measurement design. Report actual Pin results only after posting.

## Reddit participation

Follow [Reddit Rules](https://redditinc.com/policies/reddit-rules) and [Reddit's self-promotion guidance](https://www.reddit.com/r/reddit.com/wiki/selfpromotion/) plus the specific community's current rules. There is no universal numerical ratio that overrides a moderator's rules. Moderator permission can be required for links or surveys; inspect each community before posting.

Use a clearly affiliated account and help with a concrete nonclinical question in the thread itself. Include useful public primary sources even when no ThePetClub link is appropriate. Disclose the site relationship when mentioning the site, and link only where the rules and question warrant it. Avoid affiliate links, repeated cross-posts, unsolicited messages, votes from coordinated accounts and automated replies. Health emergencies belong with a veterinarian, not a promotional thread.

Prepared response for a relevant Canadian pet-cost discussion, subject to the community's rules:

“I work on ThePetClub.ca. A useful way to estimate costs is to separate one-time equipment, regular food and litter, irregular expenses, and an emergency reserve. Get local quotes and ask clinics what each estimate includes; a national average can hide large differences. For insurance, compare the provincial policy's exclusions, deductible, reimbursement and limits rather than only the premium.”

This text has not been posted. Add a site link only if the particular community permits it and it adds something the full answer does not cover. Save the thread URL and any moderator permission before publication; do not fabricate engagement or traffic.
